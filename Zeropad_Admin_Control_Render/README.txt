Zeropad Render setup

Build command:
npm install

Start command:
npm start

Environment variables:
ADMIN_PASSWORD=your-private-password
SESSION_SECRET=a-long-random-secret
DB_PATH=/var/data/zeropad.db

Render Persistent Disk:
Mount path: /var/data

Default admin password if ADMIN_PASSWORD is not set:
change-me-now

Advertising:
- Users only submit company name, site, description, and budget.
- Minimum budget is $5.
- Default CPC is $0.10.
- Payment/contact email: london.aneta@gmail.com
- Administrator creates the final ad.
- Administrator controls headline, description, URL, slot, status, budget, balance, CPC and admin notes.
- Administrator can modify or delete campaigns and edit/disable users.
- Only campaigns set to ACTIVE and assigned Slot 1, 2, or 3 appear on the homepage.
